When reporting a problem

  • Pension Planner version.
  • iPhone/iPad or Mac.
  • Your OS version.
  • What you were doing before the problem occurred.
  • The exact error message or screenshot if available.
Protect your financial information. Do not send passwords, account credentials, National Insurance numbers or unnecessary financial documents.

Common checks

A forecast looks unexpected

Review Model Health, then inspect Annual Detail from the first tax year where the result changes materially.

Mac and iPhone show different scenarios

Live scenario libraries are separate. Use manual backup/export and import when you intentionally want to transfer the complete library.

A tax result looks surprising

Check each person’s tax region, taxable flags, first-year context, pension access strategy and any GIA cost-basis/dividend inputs.

Feature requests

Describe the planning question you want to answer. This helps distinguish useful modelling improvements from unnecessary complexity.

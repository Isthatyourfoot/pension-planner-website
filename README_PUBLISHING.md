# Pension Planner Website — Publishing Guide (v1.1)

This package updates the Pension Planner website to include explanatory diagrams and a more polished visual design.

## Included enhancements
- Visual homepage with overview diagram
- GIA modelling diagram
- Tax-efficient withdrawal strategy diagram
- Data & privacy flow diagram
- Refreshed page styling
- Support, Privacy, Data & Security and Disclaimer pages retained

## Deployment
If your website is already hosted on GitHub Pages:

1. Keep a copy of the current repository contents.
2. Replace the repository contents with the contents of this package.
3. Commit the changes to the main branch.
4. GitHub Pages will republish automatically.
